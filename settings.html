Protection settings

Protection profile

Profiles change the default filter selection. Balanced is recommended for everyday browsing.

Filter lists

More lists can catch more trackers, but overlapping lists increase memory use and the chance of site breakage. uBlock filters are kept enabled because they are optimized for uBO-style filtering.

—

Custom filter lists

Subscribe to a public Adblock-compatible list by URL. Updates use a local cache when possible.

My filters

One rule per line. Network rules use Adblock syntax. Cosmetic rules use example.com##.advertisement.

Privacy protection

Fingerprinting resistance is enabled by default. Strict browser-level resistance can improve privacy but may affect compatibility.

Disabled sites

PrivaBlock stays off only for domains you disable from the popup power button.

Diagnostics

The logger records requests only while the logger is open, following the same low-overhead principle as uBlock Origin.
